# Module 00 — Course Setup

## What This Module Teaches

How to prepare for the course: required skills, Azure subscription safety, billing awareness, and consistent lab naming so resources are easy to find and delete.

## Learning Objectives

- Confirm you meet student prerequisites (Linux, Git, Docker, CI/CD basics)
- Set up an Azure subscription safely (MFA on Entra, Cost Management budget, no Owner for daily work)
- Understand lab naming conventions and placeholder values
- Know the default lab region (`southeastasia`) and when to change it

## Lab Outcome

No hands-on Azure lab in this module. You will have a safe subscription, local tools checked, and a naming plan before Phase 1.

## Estimated Time

1–2 hours

## Cost Warning

Low risk — mostly subscription configuration. Enabling Cost Management budgets is free; avoid creating billable resources until Module 03.

## Cleanup Reminder

If you created test resources while exploring the Portal, delete them (or delete the resource group) before starting console labs. Use [azure-subscription-safety.md](azure-subscription-safety.md) as your checklist.
