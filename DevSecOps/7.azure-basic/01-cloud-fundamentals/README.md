# Module 01 — Cloud Fundamentals

## What This Module Teaches

Core cloud computing concepts before touching Azure: what the cloud is, service models (SaaS, PaaS, IaaS), deployment models, on-prem comparison, and pricing basics.

## Learning Objectives

- Explain cloud computing in simple terms
- Compare SaaS, PaaS, and IaaS with real-world examples
- Describe public, private, and hybrid cloud
- List trade-offs between on-premises and cloud
- Understand pay-as-you-go, reserved, and spot pricing at a high level

## Lab Outcome

Theory only — no Azure resources. You will be able to discuss cloud fundamentals in interviews and team meetings.

## Estimated Time

3–4 hours

## Cost Warning

None — this module is reading and diagrams only. No Azure subscription usage required.
