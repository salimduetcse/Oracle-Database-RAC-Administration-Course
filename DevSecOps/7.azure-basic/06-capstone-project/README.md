# Module 06 — Capstone Projects

## What This Module Teaches

End-to-end projects combining Portal, CLI, and Terraform skills into portfolio-ready work.

## Learning Objectives

- Deploy a static site on Azure Blob Storage with security awareness
- Build nginx on a VM in a custom VNet
- Run a containerized app on Azure Container Apps
- Perform subscription-wide cleanup and revision

## Lab Outcome

Three capstone projects plus a final cleanup checklist and 30 revision questions.

## Estimated Time

8–10 hours

## Cost Warning

**Medium** — especially Project 3 (Container Apps + ACR). Destroy resources immediately after each project.
