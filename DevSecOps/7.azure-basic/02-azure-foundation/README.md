# Module 02 — Azure Foundation

## What This Module Teaches

Azure-specific foundations: global infrastructure, regions and AZs, Well-Architected Framework, Cloud Adoption Framework, shared responsibility, and basic security concepts before Portal labs.

## Learning Objectives

- Describe Azure global infrastructure (regions, AZs, edge locations)
- Explain the pillars of the Azure Well-Architected Framework at a high level
- Understand the Microsoft Cloud Adoption Framework for organizational change
- Distinguish Microsoft vs customer responsibilities in the shared responsibility model
- Apply basic security principles (least privilege, MFA, Entra ID, RBAC, Key Vault awareness)

## Lab Outcome

Theory only — no Azure resources. You will understand how Azure is organized and how to think about secure, well-architected workloads.

## Estimated Time

4–5 hours

## Cost Warning

None — theory and diagrams only.
