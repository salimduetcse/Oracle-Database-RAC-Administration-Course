# CLI Lab — S3

Repeat [Console lab 05](../../03-console-labs/05-s3/README.md) using AWS CLI.

---

## 1. Theory Reminder

- **Bucket** = global unique name; **objects** have **keys**
- **Block Public Access** should stay ON for private labs
- **Versioning** keeps object history
- High-level `aws s3` commands + low-level `aws s3api`

---

## 2. Setup Variables

```bash
export AWS_PROFILE=aws-basic-lab
export AWS_REGION=ap-southeast-1
export AWS_PAGER=""
export YOURNAME="<yourname>"
export BUCKET="devops-lab-${YOURNAME}-cli-bucket-$(date +%Y%m)"
```

---

## 3. Resource Creation Commands

### 3.1 Create bucket

```bash
aws s3api create-bucket \
  --bucket "$BUCKET" \
  --region ap-southeast-1 \
  --create-bucket-configuration LocationConstraint=ap-southeast-1 \
  --profile aws-basic-lab

# Block public access (verify all true)
aws s3api put-public-access-block \
  --bucket "$BUCKET" \
  --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true \
  --profile aws-basic-lab --region ap-southeast-1

# Default encryption
aws s3api put-bucket-encryption \
  --bucket "$BUCKET" \
  --server-side-encryption-configuration \
    '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}' \
  --profile aws-basic-lab --region ap-southeast-1
```

### 3.2 Upload objects

```bash
echo "CLI lab version 1" > hello.txt

aws s3 cp hello.txt "s3://${BUCKET}/labs/week1/hello.txt" \
  --profile aws-basic-lab --region ap-southeast-1

aws s3 cp hello.txt "s3://${BUCKET}/labs/week1/readme.txt" \
  --profile aws-basic-lab --region ap-southeast-1
```

### 3.3 Enable versioning

```bash
aws s3api put-bucket-versioning \
  --bucket "$BUCKET" \
  --versioning-configuration Status=Enabled \
  --profile aws-basic-lab --region ap-southeast-1

echo "CLI lab version 2" > hello.txt
aws s3 cp hello.txt "s3://${BUCKET}/labs/week1/hello.txt" \
  --profile aws-basic-lab --region ap-southeast-1
```

### 3.4 Bucket policy (private — IAM user only)

```bash
export ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text --profile aws-basic-lab)

cat > /tmp/bucket-policy.json << EOF
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowLabUserList",
      "Effect": "Allow",
      "Principal": {"AWS": "arn:aws:iam::${ACCOUNT_ID}:user/devops-lab-${YOURNAME}-user"},
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::${BUCKET}"
    },
    {
      "Sid": "AllowLabUserGet",
      "Effect": "Allow",
      "Principal": {"AWS": "arn:aws:iam::${ACCOUNT_ID}:user/devops-lab-${YOURNAME}-user"},
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::${BUCKET}/*"
    }
  ]
}
EOF

aws s3api put-bucket-policy \
  --bucket "$BUCKET" \
  --policy file:///tmp/bucket-policy.json \
  --profile aws-basic-lab --region ap-southeast-1

rm -f /tmp/bucket-policy.json
```

## 4. Validation Commands

```bash
# List objects
aws s3 ls "s3://${BUCKET}/" --recursive --profile aws-basic-lab --region ap-southeast-1

# Download
aws s3 cp "s3://${BUCKET}/labs/week1/hello.txt" ./downloaded-hello.txt \
  --profile aws-basic-lab --region ap-southeast-1
cat downloaded-hello.txt

# List versions
aws s3api list-object-versions \
  --bucket "$BUCKET" --prefix labs/week1/hello.txt \
  --profile aws-basic-lab --region ap-southeast-1 \
  --query "Versions[].{Key:Key,VersionId:VersionId,IsLatest:IsLatest}"

# Bucket encryption
aws s3api get-bucket-encryption --bucket "$BUCKET" \
  --profile aws-basic-lab --region ap-southeast-1
```

| Output | Meaning |
|--------|---------|
| Two versions of `hello.txt` | Versioning works |
| `SSEAlgorithm: AES256` | Encryption enabled |

## 5. Cleanup Commands

```bash
# Delete all object versions (versioned bucket)
aws s3api list-object-versions --bucket "$BUCKET" --profile aws-basic-lab --region ap-southeast-1 \
  --output json > /tmp/versions.json

# Simple force delete (handles versions in many cases)
aws s3 rb "s3://${BUCKET}" --force --profile aws-basic-lab --region ap-southeast-1

# Verify
aws s3 ls --profile aws-basic-lab --region ap-southeast-1 | grep "$BUCKET" || echo "Bucket deleted"
```

If `--force` fails, delete versions manually:

```bash
aws s3api delete-objects --bucket "$BUCKET" --profile aws-basic-lab --region ap-southeast-1 \
  --delete "$(aws s3api list-object-versions --bucket "$BUCKET" --profile aws-basic-lab --region ap-southeast-1 \
  --query '{Objects: Versions[].{Key:Key,VersionId:VersionId}}')"
```

Then:

```bash
aws s3 rb "s3://${BUCKET}" --profile aws-basic-lab --region ap-southeast-1
```

## 6. Troubleshooting

| Problem | Solution |
|---------|----------|
| `BucketAlreadyExists` | Change bucket name suffix |
| `IllegalLocationConstraintException` | Use `LocationConstraint=ap-southeast-1` |
| Cannot delete bucket | Empty all versions first |
| Access denied on policy | Check Principal ARN |
