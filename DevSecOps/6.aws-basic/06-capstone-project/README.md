# Module 06 — Capstone Projects

## What This Module Teaches

End-to-end projects combining Console, CLI, and Terraform skills into portfolio-ready work.

## Learning Objectives

- Deploy a static site on S3 with security awareness
- Build nginx on EC2 in a custom VPC
- Run a containerized app on ECS behind ALB
- Perform account-wide cleanup and revision

## Lab Outcome

Three capstone projects plus a final cleanup checklist and 30 revision questions.

## Estimated Time

8–10 hours

## Cost Warning

**Medium** — especially Project 3 (ECS + ALB). Destroy resources immediately after each project.
