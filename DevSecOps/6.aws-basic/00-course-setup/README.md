# Module 00 — Course Setup

## What This Module Teaches

How to prepare for the course: required skills, AWS account safety, billing awareness, and consistent lab naming so resources are easy to find and delete.

## Learning Objectives

- Confirm you meet student prerequisites (Linux, Git, Docker, CI/CD basics)
- Set up an AWS account safely (MFA, billing alerts, no root for daily work)
- Understand lab naming conventions and placeholder values
- Know the default lab region (`ap-southeast-1`) and when to change it

## Lab Outcome

No hands-on AWS lab in this module. You will have a safe account, local tools checked, and a naming plan before Phase 1.

## Estimated Time

1–2 hours

## Cost Warning

Low risk — mostly account configuration. Enabling some services (e.g. detailed billing) is free; avoid creating billable resources until Module 03.

## Cleanup Reminder

If you created test resources while exploring the Console, delete them before starting console labs. Use [aws-account-safety.md](aws-account-safety.md) as your checklist.
