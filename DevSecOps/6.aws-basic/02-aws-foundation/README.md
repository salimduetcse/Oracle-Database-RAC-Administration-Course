# Module 02 — AWS Foundation

## What This Module Teaches

AWS-specific foundations: global infrastructure, regions and AZs, Well-Architected Framework, Cloud Adoption Framework, shared responsibility, and basic security concepts before console labs.

## Learning Objectives

- Describe AWS global infrastructure (regions, AZs, edge locations)
- Explain the six pillars of the Well-Architected Framework at a high level
- Understand the AWS Cloud Adoption Framework for organizational change
- Distinguish AWS vs customer responsibilities in the shared responsibility model
- Apply basic security principles (least privilege, MFA, encryption awareness)

## Lab Outcome

Theory only — no AWS resources. You will understand how AWS is organized and how to think about secure, well-architected workloads.

## Estimated Time

4–5 hours

## Cost Warning

None — theory and diagrams only.
